# NeuroOS

ML-Guided JIT Compiler & Self-Modifying Distributed System in C++

## Components

- **Neural JIT Compiler** - ML-guided optimization
- **NUMA-Aware Tiered Allocator** - Predictive memory management  
- **Distributed PBFT Consensus** - Byzantine fault tolerance
- **Self-Patching System** - Hot-patching capability

## Build

```bash
cmake -B build
cmake --build build
```
